# 鼠标位置实时监控

一个实时显示鼠标屏幕坐标的小工具，用 Python 编写。

## 功能

- 实时显示鼠标当前位置的 (X, Y) 坐标
- 每 0.2 秒刷新一次，终端原地更新不刷屏
- 按 Ctrl+C 停止

## 环境要求

- Python 3.8 及以上
- Windows 系统

## 安装依赖

```bash
pip install pyautogui
```

## 使用方法

```bash
python mouse.py
```

运行后终端会持续显示当前鼠标坐标，移动鼠标即可看到数字变化。

## 效果示例

```
鼠标位置: (960, 540)
鼠标位置: (961, 541)
```
